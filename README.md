# Taskline

Список задач с тегами, сроками и ручным порядком.

[Открыть приложение](https://denis-zag.gitverse.site/react-taskline/) · [Исходное объявление](https://www.weblancer.net/freelance/veb-programmirovanie-31/react-prilozhenie-todo-list-1137418/)

## Возможности

React, английские элементы интерфейса и имена переменных; создание, просмотр, редактирование и удаление задач; теги и фильтр; поиск по описанию; ручной порядок и сортировка по обновлению; срок с отсчётом; меню Tasks/About; адаптация до 500 px.

## Быстрый запуск

Готовая сборка находится в `public/`. Для запуска нужен Node.js 22 или новее:

```text
node preview.mjs
```

Либо дважды нажмите `start.cmd` в Windows. Откройте http://127.0.0.1:8080/ . Для запуска готовой сборки устанавливать библиотеки не нужно.

## Сборка из исходников

```text
npm ci
npm run build
npm start
```

React 19.2.6, esbuild. Зависимости нужны только для изменения и сборки исходников. Внешних библиотек с CDN при работе нет.

## Проверка

```text
npm test
```

Браузерная проверка использует установленный Google Chrome в Windows. На другой системе измените executablePath в tests/browser.mjs. Отчёт — info/TEST_RESULTS.md; настоящие скриншоты — evidence/.

## Данные

Записи хранятся в LocalStorage этого браузера на этом адресе сайта. Общей базы и авторизации нет. Другой посетитель не увидит ваши записи. Очистка браузера удаляет их; перед очисткой используйте JSON-копию. Данные локального адреса и публичного сайта не синхронизируются. Файлы резервных копий могут содержать введённые данные. Не используйте реальные персональные или конфиденциальные сведения в публичной демонстрации.
